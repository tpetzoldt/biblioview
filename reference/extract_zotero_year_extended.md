# Extract Year from Zotero Date Fields (including BCE / Ancient Dates)

Extract Year from Zotero Date Fields (including BCE / Ancient Dates)

## Usage

``` r
extract_zotero_year_extended(date_vec)
```

## Arguments

- date_vec:

  Character vector of raw date strings from Zotero.

## Value

Character vector containing year strings (e.g., "2024", "384 BCE",
"-0383", or NA).
